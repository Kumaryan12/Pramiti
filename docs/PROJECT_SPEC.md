# PRAMITI

Prototype for the GIFT FutureLab Grand Challenge 2026–27. A browser signs spending mandates, an independent verifier checks shopping-agent proposals, and reviewers handle eligible exceptions before simulated settlement. The evidence chain records the inputs and decisions.

1. Deliver a runnable shopping sandbox with Ed25519 approval, deterministic verification, human review, simulated settlement and evidence verification.
2. Add semantic-consistency features, gradient boosting and class-conditional split conformal prediction.
3. Compare four policy baselines using synthetic payment fixtures and report measured outcomes.
4. Package the stack for Render with PostgreSQL. Use SQLite for local development.
